About Candidate

Engineered for Applied Intelligence

A grounded Computer Engineering background combining hardware understanding, robust software architecture, and practical machine learning solutions.

I am a fresh Computer Engineering graduate from The British University in Egypt (BUE). My passion lies at the intersection of Artificial Intelligence, Computer Vision, Data Analysis, and Systems Engineering—building intelligent applications that solve real human and business problems.

Rather than theoretical prototypes, I strive to build end-to-end, functional systems. For my graduation project, I trained deep learning instance segmentation models (YOLOv11m-seg) on the CarDD dataset to automate automotive damage inspection and repair estimation, packaging it into a real-time mobile app. For my dissertation, I engineered a computer vision assistive communication system that allows individuals with severe motor impairments to communicate via Morse code using only a standard laptop webcam.

My hands-on experience also spans AWS cloud architectures (Athena, Lambda, S3, QuickSight), enterprise network security (Juniper SRX), and cybersecurity pen-testing, giving me a solid engineering discipline across the full software lifecycle.
